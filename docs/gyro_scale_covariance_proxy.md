# 陀螺比例因子残差的区间协方差代理

`imu.gyr_scale_std` 是无量纲标准差，默认 `0.005`（0.5%），配置为 `0` 关闭。
它不是比例因子标定值，也不修正 IMU 测量：

```yaml
imu:
  gyr_scale_std: 0.005  # 0.5%（默认）；0 关闭
```

YAML 不含此项时取默认 `0.005`；`IntegrationParameters` 结构体本身的默认仍是 `0`（直接构造的预积分，如单测，不受影响）。在实际启动使用的 YAML 中配置，重启节点；
启用 `base.print_config_on_startup` 后确认启动日志中的 `gyr_scale_std`。
参数位于公开配置/预积分结构体中，部署时应一起重建依赖它们的包。

## 实现口径

每个 `PreintegrationNormal` 区间累计虚拟 IMU 坐标轴下的去偏转角：

```text
theta_axis = sum(dtheta_i - bg_linearization * dt_i)
Q_proxy = diag((gyr_scale_std * theta_axis)^2)
```

这里是各轴有符号增量之和，不是 `Log(delta_q)`，不取绝对值累加，也不把
双子样交叉项作为单轴测量转角。偏置采用该区间预积分的线性化值；重积分时
清零累计量，按更新后的偏置重新计算。

计算平方根信息矩阵时，复制原始 15 维协方差，仅向副本的姿态块
`block<3,3>(6,6)` 加入 `Q_proxy`。传播协方差、运动积分、状态维度、白噪声、
偏置过程噪声、视觉因子与鲁棒核均不改变。信息矩阵缓存失效时重新构造副本，
不会因重复求值或继续添加 IMU 而反复累计代理项。

它近似表达区间内强相关比例因子残差，不应改为每步增加
`(s * |omega|)^2 * dt` 的白噪声。它也没有完整表示位置/速度耦合、多轴误差
传输及跨区间相关性；独立区间代理不能替代显式比例因子状态。已有离线预判
支持关键帧尺度使用这一近似，不据此外推长区间表现。

## 验证与实验

新增测试覆盖：

- 配置 `0` 使用原始协方差；非零代理不改变积分状态或原始协方差。
- 使用去偏后的区间转角，重复求值不叠加，追加采样后与新建对象一致。
- 更换偏置重积分后，协方差和信息矩阵与新建对象一致。
- 去偏角速度为零时不增加代理项。
- `0 / 0.005 / 0.01` 下，四组解析雅可比与数值差分一致。

这些 C++ 测试需在支持的容器/板端编译运行；本地静态检查不代表测试通过。

先比较 `0 / 0.005 / 0.01`，其余配置、模型和二进制版本保持一致：

- 目标序列：outdoors3/5，以及 outdoors2/4 的末尾室内段。
- 回归序列：room1/3、corridor1、magistrale1。
- 主要指标：GT 倾斜误差、速度偏差、路程比、`stereo_scale`、ATE/RPE；
  ATE 同时报全段对齐和首段对齐。
- 结合原始旋转差、跨帧视觉约束、外点与重初始化判断。只因协方差增大而使
  归一化 IMU 残差下降，不能算成功；`dR_diff_deg` 也不是求解前后修正量。

## 板端实测（2026-10-16，TUM-VI，单次）

- outdoors3：`0.005` 压住开头 38～62 s 的发散（`0` 时 7 次几乎都发散）；outdoors5 `0` 发散
  （路程比 5.37）、`0.005` 正常（1.04）。`0.01 / 0.02` 对末段没有额外帮助，不再增大。
- 开头段的改善来自区间姿态信息被放松；末段 827～834 s 的偏移是另一个问题，
  根因见 `docs/preintegration_rot_jacobian_sign.md`（旋转雅可比符号），与本参数无关。
- 个别序列有代价（outdoors1/7、magistrale1、slides1/3 的单次 ATE 变大），且当时缺同二进制
  `0` 的对照。默认值定为 `0.005` 是基于发散序列的改善，非 TUM-VI 的部署配置若有回退，
  在有效 YAML 里写 `gyr_scale_std: 0`。

回退方式：将有效 YAML 中此项设为 `0` 并重启。
