ms_fusion_loop 回环实现逻辑

基于 VINS PoseGraph 的 ROS2 独立节点：DBoW3 视觉词袋检索候选 → Mutual NN + PnP 几何验证 → Ceres 位姿图优化 → 将 drift 回写到实时里程计。 本文按流水线与文件/函数逐项说明。

1. 架构总览

包路径：ros_wrapper/src/ms_fusion_loop/

运行时只做回环检测与位姿图优化，不提取特征。描述子由 ms_fusion 前端在关键帧上产出，经 ROS topic 送入本节点。

检索

DBoW3 Vocabulary + Database，用 BoW 描述子找历史相似帧

验证

Mutual NN + Lowe ratio + PnP RANSAC + 相对位姿门限

优化

4DoF（有 IMU）或 6DoF（纯 VO）Ceres 位姿图

5. DBoW3 候选检索

入口：PoseGraph::detectLoopCandidates

  1. 将关键帧 bow_descriptors 转为 float，经 Vocabulary transform 得到 BowVector
  2. dpl_db.query(bow, ret, 4, maxEligibleDatabaseId)：取 top-4，并禁止匹配最近 50 帧
  3. 立刻把本帧 BoW add 进数据库
  4. 门限：frame_index > 50 且最佳 score > loop.dbow_best_score_threshold；保留 score > loop.dbow_candidate_score_threshold 的结果映射为 keyframe index（默认分别为 0.60、0.40）
  5. 候选收窄：在上一步之上再叠加 score >= best_score * loop.dbow_candidate_relative_ratio，且最多保留 loop.dbow_max_candidates 个（默认 0.90、2），减少送去几何验证的候选数；实测中 dbow_candidate_score_threshold 基本筛不掉候选（top-4 常年塞满），真正起作用的是这一步

6. 几何验证

入口：KeyFrame::findConnection

  1. 要求当前帧 landmark_descriptors 与 point_3d 一一对齐
  2. matchMutualNNLowe(landmark_desc, old_kf->bow_descriptors)：双向 Mutual NN + Lowe ratio（0.8）
  3. 组装 3D–2D；旧帧像素经 pixelToNormalized 反投影
  4. 匹配数 ≥ min_loop_num → PnPRANSAC
  5. 内点数仍够，且相对 yaw < 30°、平移 < 20 m → 接受，写入 has_loop / loop_index / loop_info
在线验证时：当前帧用 landmark 描述子，历史帧用压缩后的 BoW 检索描述子。 历史帧的 landmark/3D 在加入位姿图后会被释放以省内存。

7. 位姿图优化

入口：optimize4DoF / optimize6DoF（由 loop.use_imu 选择）。 Ceres 优化的是一段关键帧的位姿图，不是特征点，也不重跑 VIO。 范围：earliest_loop_index → 当前闭环关键帧；锚点固定；最多 5 次迭代。

4DoF（use_imu=true）

优化 x, y, z, yaw；pitch/roll 固定（取自 VIO）。

  • 近邻边：FourDOFError（同 sequence、间隔 ≤4，无 Huber）
  • 回环边（默认，graph_loop_split_residual=false）：FourDOFWeightError + HuberLoss(0.1)（yaw 残差另 /10）
  • 回环边（graph_loop_split_residual=true）：拆成 LoopTranslationError（3 维，/graph_loop_sigma_t_m）与 LoopYawError（1 维，/graph_loop_sigma_yaw_deg），各自独立 HuberLoss（阈值单位为 sigma；平移的 Huber 作用在 ‖r_t‖ 上）；graph_loop_translation_enable=false 时只保留 yaw

6DoF（纯 VO）

全姿态四元数 + 平移。

  • 近邻 / 回环均用 RelativeRTError
  • 仅回环边加 Huber（默认旧实现一个 HuberLoss(0.1)；拆分模式下平移、yaw 各一个）

Ceres 输入是什么，要优化什么

优化变量

4DoF6DoF
每帧平移 t∈R³ + yaw平移 t + 四元数 q
固定pitch/roll 不优化—
锚点first_looped 或 sequence==0 的位姿 SetConstant

输入（残差边，测量为常数）

  1. 短程顺序边：同序列邻居 j=1..4，用建图时 VIO 相对位姿作观测 （4DoF：相对 t+yaw；6DoF：相对 t+q）。loss=NULL，更信短程 VIO。
  2. 回环边：若 has_loop，测量 = loop_info 的相对 RT（PnP 几何验证结果）。 带 Huber。不把描述子/3D 点/IMU 预积分送进 Ceres——那些只在前面产出 loop_info 与 VIO。

优化后：窗口内写 T_w_i/R_w_i → 用 cur 优化 vs VIO 更新 r_drift/t_drift。

一句话：输入 = VIO 短程相对运动 + 回环相对 RT；优化 = 窗口内各 KF 位姿（锚点固定）。

HuberLoss 做什么

Ceres 鲁棒核：残差大时减弱该边对优化的拉力，减轻错误回环把轨迹拧歪。 本工程仅回环边使用 Huber（默认旧实现是 new ceres::HuberLoss(0.1)，拆分模式下平移、yaw 各一个，阈值由 graph_loop_huber_t / graph_loop_huber_yaw 配置）；短程 VIO 边不加。

Ceres 对残差平方和 s = ||r||² 施加损失 ρ(s)（参数 δ = 0.1，即代码里的 0.1）：

ρ(s) = s                         当 s ≤ δ²
ρ(s) = 2 δ √s − δ²               当 s > δ²

即 |r| ≤ δ 时与普通平方损失同阶；
   |r| > δ 时近似随 |r| 线性增长（外点权重下降）。

δ = 0.1  →  δ² = 0.01

等价理解：小残差按二次惩罚；超过阈值后「打折」，假阳性 / 噪声大的 loop 边影响力变小。 （Ceres 实现为缩放形式 a²·ρ(s/a²)，a=δ，上式即展开结果。）

4DoF 回环（默认旧实现）还有额外设计：yaw 分量在代价里再 /10，进一步降低朝向噪声的影响。注意：近邻边链很长时，这会让回环几乎改不动 yaw（实测 yaw 差 13.5° 只改 0.04°）；拆分模式用 graph_loop_sigma_yaw_deg 显式表达 yaw 权重。

8. Drift 校正

  • 4DoF：yaw_drift + 平移 drift，只校正 yaw 旋转
  • 6DoF：r_drift = cur_R * vio_Rᵀ，全姿态
  • vio_callback：先乘 sequence 对齐 w_*，再乘 r_drift/t_drift，发布校正 odom

16. 与 ms_fusion 的互动

两个独立 ROS2 节点，由 yaml loop.enable=true 时 msf_robot.launch.py 同启。ms_fusion 负责感知 + VIO + 关键帧打包发布； ms_fusion_loop 只做检索 / 几何验证 / 位姿图，不取图、不提特征。

ms_fusion 产出

  • 关键帧：pose / point / descriptors / extrinsic（同 stamp）
  • 连续：/odometry_vio（原始 VIO）

ms_fusion_loop 回馈

  • 订阅上述话题 + 高频 VIO
  • 发布校正后的 /odometry（对外主输出）
  • 不回写 ms_fusion 内部状态（单向纠偏）
约定：/odometry_vio = 原始 VIO； /odometry = 回环 drift 修正后的最终里程计。下游导航应订阅后者。

map 上怎么「插值」

  1. 像素坐标缩放到 map：mx = u · spatial_w / image_w，my = v · spatial_h / image_h
  2. 每个通道在 (mx,my) 四邻域做双线性插值（sampleChannel）
  3. 得到的 D 维向量再 L2 归一化 → 单位向量，供后续距离比较

实现：sampleDescriptorsFromMap（XFeat / SuperPoint 共用）。 这是 CPU 插值，不是再跑一遍网络。

为什么描述子可以做「差值 / L2」

这里的「差值」指匹配时用欧氏距离 \(d(\mathbf{a},\mathbf{b})=\|\mathbf{a}-\mathbf{b}\|_2=\sqrt{\sum_i(a_i-b_i)^2}\) （公式里确实逐维相减，但最终用的是一个标量距离，不是把差分向量当新特征）。

1. 训练成度量嵌入

SuperPoint / XFeat 用对应点 / 对比学习，使「同一 3D 点不同视角」的描述子靠近、 「不同点」拉开。空间设计目标就是：视觉相似 ≈ 向量接近，因此 L2（或余弦）可当相似度。

2. 归一化后 L2 ⇔ 余弦

采样后做单位化。对 \(\|\mathbf{a}\|=\|\mathbf{b}\|=1\)： \(\|\mathbf{a}-\mathbf{b}\|_2^2 = 2-2\mathbf{a}\cdot\mathbf{b}\)。 L2 小 ⇔ 点积大 ⇔ 夹角小。Mutual NN 用 L2 与按余弦排序单调一致。

3. 稠密 map 可插值的原因

描述子来自 CNN 特征图，相邻格子语义连续；双线性插值是在同一嵌入场上平滑取值， 插值结果仍落在同一度量空间，故任意亚像素位置也能继续用 L2 比。 本仓库 XFeat 与 SuperPoint 共用 sampleDescriptorsFromMap，原理相同，仅 D 与权重不同。

Mutual NN 在代码里：先对行做 L2 归一化，再 l2Distance 找双向最近邻 + Lowe ratio（0.8）。 当前帧用 ② landmark，历史帧用 ① bow（可能从 int8 还原 float）。
不是任意特征都能这样用：二值 BRIEF 更常用汉明距；未归一化的原始激活尺度乱跳时不宜直接欧氏比较。 SuperPoint/XFeat 是「为距离匹配训好的 float 嵌入」，所以可以。

词直方图检索怎么实现

分三步：量化成 Bow → 倒排索引累加分 → 阈值筛候选。

1) 描述子 → BowVector（量化）

  1. int8 bow_descriptors 还原 float（若需要）。
  2. 对每一行描述子：从词树根往下，每层选与节点中心距离最小的子节点，落到叶子 → word_id；权重取该词的 IDF（TF-IDF）。
  3. 同一词多次出现则 addWeight 累加（相当于 TF×IDF）。
  4. L1 打分要求向量归一化 → 得到稀疏 map：{word_id → weight}，即词直方图。

2) 倒排索引查询（Database::queryL1）

DB 对每个 word 维护一行倒排表：m_ifile[word] = [(entry_id, weight), …]（按 entry 有序）。 入库 add(bow) 时把本帧出现过的词写入对应行。

  1. 遍历查询 Bow 里每个词，扫该词倒排行；跳过 entry_id ≥ max_id（本工程用「最近约 50 帧」作时间窗屏蔽）。
  2. 对每个命中历史条目累加 L1 相关项： |q−d| − |q| − |d|（再缩放成 [0,1] 相似度；与直接算 ‖q−d‖₁ 等价的高效写法）。
  3. 按分数排序，取 top-4（query(..., 4, maxEligibleId)）。

复杂度约「查询非零词数 × 每词倒排长度」，远小于两两比全量直方图。 本工程 use_di=false，不用 direct index，只靠倒排 + Bow。

3) PoseGraph 侧门槛

score_best > 0.05 且 frame_index > 50
  → 保留 score > 0.015 的结果
  → database_id → keyframe_index（database_to_keyframe）
  → 交给 findConnection 做几何验证
检索只比「词权重向量」相似，不保证同一场景点；假阳性靠后续 Mutual NN + PnP 滤掉。

检索的是什么，和在线流程的关系

检索输出是历史关键帧候选 ID（最多约 4 个，带 score）， 不是位姿、不是匹配点对、也不是原始描述子。

在整条在线链路里，DBoW 只负责缩小搜索范围：

  • 无候选 / 分数不够 / 几何失败：本帧只入库，不纠漂移。

视角变化不大时，近邻 keyframe 岂不是很像？

对。连续关键帧场景重叠大，词直方图往往非常像——BoW 分数最高的经常是刚走过的几帧，而不是远处的真闭环。 这是常态，工程用「时间窗 + 门槛 + 几何」把「近邻像」和「真回环」分开。

  1. 屏蔽最近约 50 个关键帧：maxEligibleDatabaseId，近邻不进 query 结果。
  2. 起步再检：frame_index > 50 才看候选。
  3. 分数门槛：最优 > 0.05，再留 > 0.015；近邻已屏蔽后，剩的是「较远但像」的候选。
  4. 几何验证：走廊重复纹理等误召回，Mutual NN + PnP 对不上就丢弃。

16.4 两套 RT、漂移假设与如何应用

回环侧实质有两套变换：① 几何验证得到的相对回环 RT（进位姿图边）； ② 图优化后得到的全局 drift（纠正实时里程计）。 跨序列时另有一次 w_r_vio / w_t_vio 对齐。图像一直连续也能回环，不必切 sequence。

① 相对回环 RT（loop_info）

  • 来源：Mutual NN → PnP-RANSAC 得旧帧世界位姿 → \(R_\text{rel}=R_\text{PnP}^\top R_\text{cur}\)， \(t_\text{rel}=R_\text{PnP}^\top(t_\text{cur}-t_\text{PnP})\)，再加相对 yaw； 过门限写入 loop_info[0..7]。
  • 用途：位姿图 loop edge；不直接改 /odometry。

② 全局 drift（r_drift / t_drift）

  • 来源：位姿图优化后，用当前 KF 的优化位姿对 VIO 位姿： 有 IMU 时 4DoF（只估 yaw）；无 IMU 时 6DoF。 含义 \(P_\text{corr}=r_\text{drift}\,P_\text{vio}+t_\text{drift}\)。
  • 用途：刷新优化窗口之后关键帧的显示位姿； vio_callback 里纠正高频 /odometry_vio → /odometry。 不写回 ms_fusion 滑窗。

漂移假设：不是「默认切成很多段乱飘」

含义
同序列（常见） VIO 在同一坐标系连续递推，误差慢慢累积；闭环后用一个全局刚体 drift 近似纠偏。 图像一直连续也能回环（DBoW 找较早 KF → NN+PnP → 图优化 → 更新 drift），不需要切 sequence。
跨序列（例外） 图像间断 / new_sequence() 时 sequence++（轨迹段号，不是 frame id）。 新段像另起坐标系；第一次跨段闭环用 w_r_vio/w_t_vio 把整段新序列刚体对齐到旧世界， 并置 sequence_loop[seq]=1（只做一次）。

跨序列对齐怎么定义

  1. 旧帧位姿 ∘ 相对回环 → 当前帧应在旧世界的位姿 \((R_w^\text{cur}, t_w^\text{cur})\)
  2. 求 \((R_w, t_w)\) 使本地 VIO 贴上该目标（有 IMU 时 \(R_w\) 只含 yaw）
  3. 写入 w_r_vio/w_t_vio，对本序列已有 KF 全部施加；之后入图与 vio_callback 先乘 w_* 再乘 drift

更新 drift 后，谁会被改？

对象行为
已发布的历史 /odometry不回写、不重放
优化窗口内关键帧 [earliest_loop … cur] 直接写 Ceres 结果到 T_w_i/R_w_i（不是旧 pose×新 drift）
cur 之后的关键帧 新 drift × 其 VIO → 刷新显示位姿
之后的实时 VIO只用最新 drift（及如有则 w_*）
各帧 vio_T/R（同序列）一般不改；改的是优化位姿 + 全局 drift
一句话：① 相对 RT 钉住「两帧该差多少」进图；② drift 把图结果压成刚体挂到「从现在起」的高频 VIO。 窗口内历史靠优化直接改 pose，不是整条旧轨迹再乘一遍新 RT。

输出层平滑（output_smooth_tau_s，默认关闭）

位姿图优化会让输出位姿一次性阶跃。设 output_smooth_tau_s = τ > 0 后， 发布的 /odometry = 未平滑位姿 + 残差：落地那一帧吸收阶跃（输出保持连续）， 之后残差按 exp(-dt/τ) 衰减（dt 取 /odometry_vio 的消息时间戳； τ=2 s 约 6 s 消除 95%）。

  • 同一把锁内先衰减旧残差、再吸收新阶跃：dp = p_old + dp_decayed − p_new， dyaw = wrap(yaw_old + dyaw_decayed − yaw_new)；新吸收的部分当帧不再衰减。连续两次校正自然叠加。
  • 时间戳重复不衰减；回退时重置时间基准，不会出现负 dt。状态只由 /odometry_vio 发布路径推进。
  • 位姿图仍使用未平滑位姿；平滑只影响发布的 /odometry。
  • 本节点不发布 TF。消息里的 twist.linear 是 /odometry_vio 的世界系速度， 经 w_r_vio、r_drift 旋转到修正后的世界系（与位置同一旋转，无平移）； 平滑开启时仍按未平滑的修正旋转，不是平滑位置的导数，衰减期间两者相差约 |残差|/τ。上游未填角速度。
  • 代价：校正后约 3τ 内输出相对未平滑位姿有滞后，heading 尚未收敛时下游会看到带残差的朝向。 离线仿真（τ=2 s）RPE 平移 0.19→0.14 m 等，整体 ATE/RMSE 几乎不变，这不代表滞后期内没有偏差。
